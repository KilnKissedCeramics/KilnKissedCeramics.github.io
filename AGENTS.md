# Kiln Kissed Ceramics — Codex Working Instructions

## Project context

- Read `README.md` at the start of each session before proposing or making
  changes. It documents the website structure, behavior, and development
  conventions.
- This repository and `AGENTS.md` are public. Never add private personal
  information, passwords, credentials, API keys, tokens, customer information,
  or other sensitive information to this file.

## Approval-first workflow

- Before editing any file, explain each proposed change and wait for explicit
  approval.
- For every proposed change, identify:
  - the expected visible or behavioral result;
  - the files likely to be affected;
  - any companion updates that may be needed, such as README documentation,
    sitemap dates, analytics, accessibility, or validation.
- Approval applies only to the changes specifically discussed. Do not bundle
  additional improvements without separate approval.
- Never silently omit a necessary companion update. Explain it and request
  approval before making it.
- After implementation, summarize the files changed, validation performed, and
  any remaining recommendations.
- Do not commit or push changes.
